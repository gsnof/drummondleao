# Publicação no GitHub Pages

Este projeto já está preparado para GitHub Pages.

1. Envie todo o conteúdo desta pasta para a branch `main` do repositório.
2. No GitHub, abra **Settings > Pages**.
3. Em **Source**, selecione **GitHub Actions**.
4. Aguarde o workflow **Deploy to GitHub Pages** terminar com sucesso.

O caminho base é detectado automaticamente pelo nome do repositório durante o GitHub Actions, então não é necessário editar `vite.config.ts` ao renomear o repositório.
